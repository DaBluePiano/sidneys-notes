# 1. Nervous System

- **Function**: Coordinates responses to changes or threats, maintains homeostasis.
- **Components**:
    - **Central Nervous System (CNS)**: Brain and spinal cord; acts as control centre – receives messages, examines information, sends out messages.
    - **Peripheral Nervous System (PNS)**: Sensory receptors and nerves; informs CNS of changing conditions, transmits decisions to effectors (muscles/glands).
- Messages passed via nerve cells called neurons.

| Component | Parts                     | Function                             |
| --------- | ------------------------- | ------------------------------------ |
| CNS       | Brain, Spinal Cord        | Receive/examine/send messages        |
| PNS       | Sensory Receptors, Nerves | Detect changes, transmit to/from CNS |

# 2. Neurons

- Specialised cells that transmit/receive electrical impulses.
- **Structure**:

|Part|Function|
|---|---|
|Cell Body|Contains nucleus; enlarged part|
|Dendrites|Branching extensions; bring impulses towards cell body|
|Axon|Extension; conducts impulses away from cell body|
|Myelin Sheath|Insulates axon; speeds transmission, ensures direction|

- **Types**:

| Type            | Function                                                |
| --------------- | ------------------------------------------------------- |
| Sensory         | Transmit from sense organs to CNS                       |
| Motor           | Carry from CNS to effectors (muscles/glands)            |
| Interconnecting | Link between other neurons; pass messages correctly<br> |

![What Is a Neuron? Diagrams, Types, Function, and More|920x678](https://i0.wp.com/post.healthline.com/wp-content/uploads/2022/01/1932990_An-Easy-Guide-To-Neurons-01.jpg?w=1155&h=2007)

# 3. Disorders of the Nervous System

- **Parkinson's Disease**: Symptoms include tremors, stiffness, slow movement; affects movement control.
- **Cerebral Palsy**: Affects muscle control and movement; caused by brain damage before/during birth.
- **Multiple Sclerosis**: Immune system attacks myelin sheath; symptoms include fatigue, numbness, vision problems.

# 4. Endocrine System

- Sends chemical messages (hormones) via bloodstream to target organs; regulates homeostasis, growth, reproduction.
- **Comparison to Nervous System**:

|Aspect|Nervous System|Endocrine System|
|---|---|---|
|Speed|Fast|Slower|
|Message Type|Electrical|Chemical|
|Transport|Neurons|Bloodstream|
|Control|Central (Yes)|No|

- **Glands and Hormones**:

| Gland        | Hormone(s)               | Target                          | Main Effects                                            |
| ------------ | ------------------------ | ------------------------------- | ------------------------------------------------------- |
| Hypothalamus | Neurohormones            | Pituitary                       | Links nervous/endocrine; controls hunger, thirst, sleep |
| Pituitary    | TSH, ADH, GH             | Thyroid, Kidneys, Bones/Muscles | Thyroxine release, water reabsorption, growth           |
| Thyroid      | Thyroxine, Calcitonin    | Body cells, Blood               | Metabolism/development, decrease calcium                |
| Parathyroid  | PTH                      | Blood                           | Regulate calcium                                        |
| Adrenal      | Adrenalin                | Body cells                      | 'Fight or flight' response                              |
| Pancreas     | Insulin, Glucagon        | Liver/Muscles/Fat, Liver        | Lower/raise blood glucose                               |
| Pineal       | Melatonin                | Skin cells                      | Pigmentation, biological rhythms                        |
| Ovaries      | Progesterone, Oestrogens | Uterus, Body cells              | Uterus thickening, female characteristics/pregnancy     |
| Testes       | Testosterone             | Reproductive system, Body cells | Male characteristics, sperm production                  |

# 5. Plant Hormones

- Regulate growth in response to stimuli.
- **Phototropism**: Growth towards light.
- **Geotropism**: Growth towards gravity (roots down, shoots up).

# 8. Sexual Reproduction

- **Gamete Formation**: Sperm (testes), Ovum (ovaries) via meiosis.
- **Fertilisation**: Sperm fuses with ovum in fallopian tube → zygote.
- **Gestation**: Zygote implants in uterus, develops into embryo/fetus over ~9 months.
