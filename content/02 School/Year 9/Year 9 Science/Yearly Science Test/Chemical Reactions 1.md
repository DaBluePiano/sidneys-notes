# Chemical Reactions 1 Exam Notes

## 1. Atomic Structure

- **Subatomic Particles**:
    - **Proton**: Positively charged (+1), located in the nucleus, determines the atomic number and element identity.
    - **Neutron**: No charge (0), located in the nucleus, contributes to atomic mass, stabilizes the nucleus.
    - **Electron**: Negatively charged (-1), orbits the nucleus in energy levels/shells, involved in chemical bonding and reactions.
- Each atom has a central nucleus (protons + neutrons) with electrons orbiting around it.
- Atoms are neutral when the number of protons equals the number of electrons.
- Example: Magnesium ($\ce{Mg}$) has 12 protons, 12 neutrons (approx.), 12 electrons.

| Particle | Charge | Location                       | Function/Notes                                  |
| -------- | ------ | ------------------------------ | ----------------------------------------------- |

| Neutron  | 0      | Nucleus                        | Contributes to atomic mass; stabilizes nucleus. |
| Electron | -1     | Orbits nucleus (energy levels) | Involved in chemical bonding and reactions.     |
|          |        |                                |                                                 |

## 2. Reading the Periodic Table

- **Key Information in an Element Box**:
    - **Atomic Number**: Number of protons (and electrons in neutral atom), top of the box.
    - **Element Symbol**: 1-2 letter abbreviation, center.
    - **Element Name**: Full name, below symbol.
    - **Atomic Mass**: Average mass of atoms (protons + neutrons), bottom.
- **Metals vs Non-Metals**:

| Property          | Metals                   | Non-Metals                              |
| ----------------- | ------------------------ | --------------------------------------- |
| Location          | Left of periodic table   | Right of periodic table                 |
| Conductivity      | Good (heat/electricity)  | Poor                                    |
| Physical State    | Mostly solid, malleable  | Brittle solids, gases, liquids          |
| Electron Behavior | Lose electrons (cations) | Gain/share electrons (anions/molecules) |

- Example: Oxygen ($\ce{O}$) - Atomic number 8, atomic mass 16, non-metal.

## 3. Chemical Bonding

- **Chemical Bond**: Force holding atoms together to form compounds.
- **Ionic Bonding**:
    - Between metal (loses electrons, forms cation) and non-metal (gains electrons, forms anion).
    - Electron transfer creates oppositely charged ions that attract.
    - Results in ionic compounds (e.g., $\ce{NaCl}$ - sodium chloride).
    - Properties: High melting point, conduct electricity when dissolved/melted.
    - Example: Sodium ($\ce{Na}$) + Chlorine ($\ce{Cl}$) → $\ce{Na⁺ + Cl⁻ → NaCl}$.

![1 Formation of NaCl by ionic bonding between Na + and Cl − . |Download  Scientific Diagram|433x399](https://www.researchgate.net/publication/341838190/figure/fig1/AS:898145978417155@1591146096577/Formation-of-NaCl-by-ionic-bonding-between-Na-and-Cl.ppm)

- **Covalent Bonding** (Molecular Bonding):
    - Between non-metals, electrons are shared to achieve full outer shells.
    - Forms molecules (e.g., $\ce{H₂O}$ - water).
    - Properties: Low melting point, do not conduct electricity.
    - Example: Hydrogen ($\ce{H}$) + Oxygen ($\ce{O}$) → $\ce{H}$ shares with $\ce{H}$ to form $\ce{H2O}.$

![[image.png|500x633]]

- **Comparison Table**:

| Aspect             | Ionic Bonding           | Covalent Bonding                   |
| ------------------ | ----------------------- | ---------------------------------- |
| Elements Involved  | Metal + Non-metal       | Non-metal + Non-metal              |
| Electron Mechanism | Transfer (stealing)     | Sharing                            |
| Formed Structures  | Ionic lattice/compounds | Molecules                          |
| Examples           | $\ce{NaCl}$, $\ce{MgO}$ | $\ce{H2O}$, $\ce{CO2}$, $\ce{CH4}$ |

- **Naming Ionic Compounds**:
    - Cation (metal) name first, unchanged.
    - Anion (non-metal) name second, end with "-ide".
    - Example: Magnesium + Oxygen → Magnesium oxide ($\ce{MgO}$).
- **Writing Formulas**:
    - Determine charges (e.g., $\ce{Mg^2+}$, $\ce{O^2-}$).
    - Cross charges to balance ($\ce{Mg2O2}$ simplifies to $\ce{MgO}$).
    - Use polyatomic ions if needed (e.g., $\ce{CO3^2-}$ carbonate).

## 4. Chemical Reactions Basics

- **Chemical Reaction**: Process where atoms rearrange to form new substances; bonds break and form.
- **Evidence**: Color change, gas production, temperature change, precipitate, light/sound.
- **Reactants and Products**: Reactants (starting substances) → Products (new substances).
- **Law of Conservation of Mass**: Total mass of reactants = total mass of products; atoms are rearranged, not created/destroyed.
- **Endothermic vs Exothermic**:
    - Endothermic: Absorbs energy (feels cold), e.g., energy + reactants → products.
    - Exothermic: Releases energy (feels hot, light), e.g., reactants → products + energy.

| Type        | Energy Change   | Feels Like | Example            |
| ----------- | --------------- | ---------- | ------------------ |
| Endothermic | Absorbs energy  | Cold       | Photosynthesis     |
| Exothermic  | Releases energy | Hot/light  | Combustion of fuel |

## 5. Specific Reactions

- **Combustion Reactions**:
    - Exothermic reaction with oxygen, releases heat/light.
	- Complete: Fuel + plenty $\ce{O2}$ → $\ce{CO2}$ + $\ce{H2O}$ (e.g., Methane + Oxygen → Carbon dioxide + Water).
	- Incomplete: Limited $\ce{O2}$ → $\ce{CO}$/$\ce{C}$ + $\ce{H2O}$ (e.g., Methane + Oxygen → Carbon monoxide + Water or Carbon + Water).
    - Examples:
        - Bunsen burner (methane combustion).
        - Metals with oxygen: Metal + Oxygen → Metal oxide (e.g., Magnesium + Oxygen → Magnesium oxide); very reactive metals burn brightly, moderately glow.
        - Respiration: Glucose + Oxygen → Carbon dioxide + Water + Energy (combustion-like, provides energy for cells).

| Combustion Type | Equation Example                    | Conditions     |
| --------------- | ----------------------------------- | -------------- |
| Complete        | $\ce{CH4 + 2O2 -> CO2 + 2H2O}$      | Plenty oxygen  |
| Incomplete (CO) | $\ce{2CH4 + 3O2 -> 2CO + 4H2O}$     | Limited oxygen |
| Incomplete (C)  | $\ce{CH4 + O2 -> C + 2H2O}$         | Very limited   |
| Respiration     | $\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O}$ | In cells       |

![Combustion - Chemical Reactions, Heat, Oxidation |Britannica|499x517](https://cdn.britannica.com/65/107565-050-A57675B4/Stages-combustion-process.jpg)

- **Neutralisation Reactions**:
    - Acid + Base → Salt + Water.
    - Neutralises pH (acidic to neutral).
    - Salt: Ionic compound from acid's anion and base's cation.
    - Naming salts: Metal from base + anion from acid (e.g., Hydrochloric acid + Sodium hydroxide → Sodium chloride + Water).
    - Importance: In living systems, e.g., antacids neutralise stomach acid; digestion.

**Acid + Carbonate Reactions**:
	- Acid + Carbonate → Salt + Water + Carbon dioxide.
	- Evidence: Bubbles ($\ce{CO2}$ gas).
	- Example: Hydrochloric acid + Sodium carbonate → Sodium chloride + Water + Carbon dioxide.
	- Practical: Bi-carb soda (sodium hydrogen carbonate) decomposes with heat/acid → Sodium carbonate + $\ce{CO2}$ + $\ce{H2O}$ (used in honeycomb).

| Common Acids | Formula        | Common Bases      | Formula        | Resulting Salt Example |
| ------------ | -------------- | ----------------- | -------------- | ---------------------- |
| Hydrochloric | $\ce{HCl}$     | Sodium hydroxide  | $\ce{NaOH}$    | $\ce{NaCl}$            |
| Sulfuric     | $\ce{H2SO4}$   | Calcium hydroxide | $\ce{Ca(OH)2}$ | $\ce{CaSO4}$           |
| Nitric       | $\ce{HNO3}$    | Ammonia           | $\ce{NH3}$     | $\ce{NH4NO3}$          |
| Acetic       | $\ce{CH3COOH}$ | -                 | -              | -                      |

| Reaction Type    | General Equation                           | Example Equation                          |
| ---------------- | ------------------------------------------ | ----------------------------------------- |
| Acid + Metal     | Acid + Metal → Salt + $\ce{H2}$            | $\ce{2HCl + Mg -> MgCl2 + H2}$            |
| Acid + Base      | Acid + Base → Salt + $\ce{H2O}$            | $\ce{HCl + NaOH -> NaCl + H2O}$           |
| Acid + Carbonate | Acid + Carbonate → Salt + $\ce{H2O + CO2}$ | $\ce{2HCl + Na2CO3 -> 2NaCl + H2O + CO2}$ |
