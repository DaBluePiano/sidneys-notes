# Core
## Probability A (Core)
### Independent and Dependent Events
#### Independent events

Two events are _independent_ if one does not affect the other:

$$P(A \cap B) = P(A) \times P(B)$$

#### Dependent events

Two events are _dependent_ if one outcome affects the other.

#### Replacement
- **With replacement:** put item back → independent, probabilities unchanged.
- **Without replacement:** do not put item back → dependent, probabilities change.
- Use **tree diagrams** to model multi-step probabilities.

### Simple Tree Diagrams
- Shows all possible outcomes.
- Branch: each possible event.
- Probability: along branches.
- Outcome: result of branch.
- For equally likely events:

$$P(A) = \frac{\text{favourable outcomes}}{\text{total outcomes}} = 1 - P(\overline{A})$$

### Two-Step Events
- **With replacement:** probabilities stay the same.
- **Without replacement:** probabilities change.
- Tree diagrams without replacement reflect remaining items.

### Multi-stage Events $A \cap B$
- Tree diagrams include probabilities for non-equally likely outcomes.
- Multiply along branches for specific outcome probabilities.
- Sum probabilities to check total = 1.
- Adjust probabilities for dependent stages.
- Multiplication can replace full tree diagrams.

## Equations A (Core)
### Two and Three-Step Equations
- Apply inverse operations in reverse order.
- For formulas, substitute known values and solve for unknowns.
- Define variables clearly and express answers with correct units.

### Expanding Brackets
- **Single bracket:** multiply outside term by each inside term.
- **Double brackets:** multiply each term of first bracket by each of second; combine like terms.
- Watch for negative signs.

### Pronumerals on Both Sides
1. Expand brackets.
2. Move variables to one side.
3. Combine like terms.
4. Apply inverse operations.
- **Special cases:** same variable term cancels → no solution or infinite solutions.

### Substitution
- Replace variables with given values.
- Follow order of operations.

### Worded Questions
- Convert scenario into equation.
- Solve using appropriate method.

## Linear Relationships B (Core)
### Gradient-Intercept Form

$$y = mx + c$$

- $m$: gradient; $c$: $y$-intercept.
- Positive $m$ → line rises; negative $m$ → line falls; $m=0$ → horizontal.
- Find gradient:

$$m = \frac{y_2 - y_1}{x_2 - x_1}$$

- $y$-intercept: value of $y$ when $x=0$.

### Coordinate Geometry
- Gradient: $m = \frac{y_2 - y_1}{x_2 - x_1}$
- Midpoint: $M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$
- Distance: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
- Parallel lines: same gradient.
- Perpendicular lines: negative reciprocal gradients.
- X-intercept: set $y=0$; y-intercept: set $x=0$.

### Horizontal and Vertical Lines

| Line Type | Equation | Gradient |
|-----------|---------|----------|
| Horizontal | $y = c$ | $0$ |
| Vertical | $x = b$ | Undefined |

# Path
## Equations B (Path)
### Monic Quadratic Trinomials
#### Null Factor Law

If product = 0, one factor = 0:

$$(x - a)(x - b) = 0 \Rightarrow x = a \text{ or } x = b$$

#### Factorisation
- Monic trinomial $x^2 + bx + c$:
  - Find $p, q$ such that $p + q = b$, $pq = c$.
  - Factorise: $x^2 + bx + c = (x + p)(x + q)$
  - Solve: $(x + p)(x + q) = 0 \Rightarrow x = -p \text{ or } x = -q$

### Cubic Equations
- Two-step quadratic: $x^2 = k \Rightarrow x = \pm \sqrt{k}$, $x=0$, or no solution.
- Two-step cubic: $x^3 = k \Rightarrow x = \sqrt[3]{k}$ (unique real solution).

### Linear Inequalities
- Solve like equations; flip inequality when multiply/divide by negative.
- Hollow circle: $<$ or $>$; solid circle: $\le$ or $\ge$.
- Test solutions by substitution.

## Linear Relationships C (Path)
### Midpoint

$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$$

### Gradient

$$m = \frac{y_2 - y_1}{x_2 - x_1}$$

### Distance

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

### Other Forms of Linear Equations
- Gradient-intercept: $y = mx + c$
- General: $ax + by + c = 0$
- Point-gradient: $y - y_1 = m(x - x_1)$

### Line and Rotational Symmetry
- **Line symmetry:** shape overlaps after reflection; axis passes through centre.
- **Rotational symmetry:** shape overlaps after rotation; centre = centre of rotation; order = times overlapped in 360°.

### Transformations
- **Translation:** $(x,y) \to (x+a, y+b)$; size and orientation unchanged.
- **Reflection:** flip over a line; distances to line preserved.
- **Rotation:** turn around a point; size unchanged, orientation changes.
- **Multiple transformations:** order matters.
